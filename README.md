# Apollo Appointment Analysis

## Project Overview
This project analyzes hospital appointment data using Python and data analysis libraries. The goal is to explore appointment patterns and generate useful insights from the available data.

## Dataset
- **Appointments Dataset:** 75,000 rows and 52 columns
- **Doctors Dataset:** 320 rows and 15 columns

## Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Matplotlib and Seaborn (for visualization, if used in the notebook)

## Project Objectives
- Explore and understand the appointment dataset
- Clean and prepare data for analysis
- Analyze appointment-related trends
- Explore doctor-related information
- Identify useful patterns to support data-driven decisions

## Project Files
- `Apollo_Appointment_Analysis.ipynb` — analysis notebook
- `apollo_appointments_fact.csv` — appointment data
- `apollo_doctors_dim.csv` — doctor details

## How to Run
1. Download or clone this repository.
2. Keep the notebook and both CSV files in the same folder.
3. Install the required Python libraries.
4. Open the notebook in Jupyter Notebook.
5. Run the cells in order.
